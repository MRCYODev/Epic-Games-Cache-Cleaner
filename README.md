<h1 align="center"> Epic Games Cache Cleaner </h1>

**Epic Games Cache Cleaner** is a script designed to clean the *Epic Games Launcher* **WebCache** folder. This script can help resolve many launcher issues, related to starting games, and much more...

In simple words, it checks if the **Epic Games Launcher** is open, it close the Epic Games Launcher, and then it goes through `C:\Users\UserName\AppData\Local\EpicGamesLauncher\Saved\` and Deletes the `webcache_*` folder, and then it re-launch the **Epic Games Launcher**.
